# Android TV Leanback Guidelines

- Use native Leanback UI for best TV experience.
- Present channels as rows with large artwork and a clear live badge.
- Use ExoPlayer for playback; prefer native playback over WebView.
- Ensure D-pad focusability and large typography (H1 48-64px).
- Map remote keys for Play/Pause/Back and provide on-screen controls.
- Provide a simple settings screen for quality and captions.
