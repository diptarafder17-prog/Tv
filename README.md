# open-live-tv

Lightweight landing site and native wrappers that redirect users to a live TV stream.

## Structure
- android/MainActivity.kt
- ios/ViewController.swift
- server/package.json
- server/server.js
- site/assets/app.js
- site/assets/logo.svg
- site/assets/styles.css
- site/index.html
- site/manifest.json
- site/privacy.html
- site/terms.html
- tv/leanback-guidelines.md

## Quick start
1. Host the `site/` folder on GitHub Pages or any static host.
2. Update Android and iOS wrappers to point to your hosted landing page URL.
3. Optionally deploy `server/` to a Node host for server-side redirect.
